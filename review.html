Project Thesis Submission

  • One hardbound copy per group must be submitted to the department.
  • Students may prepare additional hardbound copies for their own future reference. If they are working in a group, any member can create their own copy.
  • A CD/DVD must be attached to the last page of the thesis using proper tape.

CD/DVD must contain all project-related soft copies:

• Project Presentation

• Project Documentation

• Project Directory

On the CD/DVD, clearly write the following details:

- Names of all group members
- Enrollment numbers of all group members
- Course and Division
- Project Title
